# build list

列出当前应用的所有构建记录

## 使用

```shell
Usage: nexus build list [options]
```

## 选项

```shell
-v, --verbose        enable verbose mode
--json               output results in JSON format (default: false)
-l, --limit <limit>  specify the number of builds to show (default: 25)
-h, --help           display help for command
```

## 示例

```shell
nexus build list
```
