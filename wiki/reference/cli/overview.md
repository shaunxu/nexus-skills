# 概述

Nexus CLI 是用于构建和部署 Nexus 应用的命令行界面工具，帮助开发者快速创建、打包、构建、部署以及分发应用。

## 安装

使用以下命令安装 Nexus CLI：

```shell
npm install -g @pc-nexus/cli@latest
```

安装完成后，你可以使用 `--version` 选项来验证是否安装正确以及获取版本信息：

```shell
nexus --version
```

使用 `--help` 选项查看所有命令。

## 升级

升级 Nexus CLI 到最新版本，推荐先完整卸载后再安装：

```powershell
npm uninstall -g @pc-nexus/cli
npm install -g @pc-nexus/cli@latest
```
