# deploy list

列出当前应用的所有部署记录

## 使用

```shell
Usage: nexus deploy list [options]
```

## 选项

```shell
-v, --verbose        enable verbose mode
--json               output results in JSON format (default: false)
-l, --limit <limit>  specify the number of deployments to show (default: 25)
-h, --help           display help for command
```

## 示例

```shell
nexus deploy list
```
