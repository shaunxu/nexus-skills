# serve bind

将 CLI 当前登录开发者账号与 PingCode 用户绑定，以便在本地  `serve`  调试时以该站点身份访问开发环境中的应用

## 使用

```shell
Usage: nexus serve bind [options]
```

## 选项

```shell
-v, --verbose  enable verbose mode
-h, --help     display help for command
```

## 示例

```shell
nexus serve bind
```
