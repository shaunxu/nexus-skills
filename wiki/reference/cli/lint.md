# lint

检查应用代码和配置文件中的常见错误和问题

## 使用

```shell
Usage: nexus lint [options]
```

## 选项

```shell
-v, --verbose  enable verbose mode
-f, --fix      automatically fix linting errors
-h, --help     display help for command
```

## 示例

执行检查

```shell
nexus lint
```

执行检查并进行自动修复

```shell
nexus lint --fix
```
