# environments

管理应用的环境

## 使用

```shell
Usage: nexus environments [options] [command]
```

## 子命令

```shell
create [options]  create a new development environment
delete [options]  delete one or more environments for your app
list [options]    list environments for your app
help [command]    display help for command
```
