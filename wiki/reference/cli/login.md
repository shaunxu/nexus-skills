# login

登录个人开发者账号

## 使用

```shell
Usage: nexus login [options]
```

## 选项

```shell
-v, --verbose        enable verbose mode
--non-interactive    run the command without input prompts
-t, --token <token>  personal access token to use
-h, --help           display help for command
```

## 示例

使用指定的访问令牌登录

```shell
nexus login  --token PERSONAL_ACCESS_TOKEN
```
