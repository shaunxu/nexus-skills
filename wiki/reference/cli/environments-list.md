# environments list

列出当前应用的所有环境

## 使用

```shell
Usage: nexus environments list [options]
```

## 选项

```shell
-v, --verbose  enable verbose mode
--json         output results in JSON format (default: false)
-h, --help     display help for command
```

## 示例

```shell
nexus environments list
```
