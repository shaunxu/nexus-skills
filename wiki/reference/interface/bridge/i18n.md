# i18n

`i18n`  API 允许你访问翻译中配置的翻译资源，使应用能够根据用户的语言和地区进行适配。

导入：

```typescript
import { i18n } from "@pc-nexus/bridge";
```

内置方法：

<table style="width: 100%; table-layout: fixed"><colgroup><col style="width: 26.41%" /><col style="width: 73.59%" /></colgroup><thead><tr><th>API</th><th>描述</th></tr></thead><tbody><tr><td><code>getTranslations</code></td><td>获取当前语言的所有翻译 json 对象，让你轻松集成第三方 i18n 框架，比如  <a href="https://www.i18next.com/">i18next</a> 。这允许你通过这些第三方 i18n 框架使用翻译资源，访问插值、格式和复数等高级翻译功能</td></tr><tr><td><code>createTranslator</code></td><td>内置了一个 Translator 提供基础的翻译功能</td></tr></tbody></table>

## getTranslations

`getTranslations` 根据指定的语言获取翻译资源文件的内容。

### 函数签名

```typescript
function getTranslations(locale?: SupportedLocaleCode): Promise<GetTranslationsResult>;

export interface TranslationsResourceContent {
    [key: string]: string | TranslationsResourceContent;
}

export interface GetTranslationsResult {
    locale: SupportedLocaleCode;
    translations: TranslationsResourceContent | null;
}
```

### 参数

<table style="width: 100%; table-layout: fixed"><colgroup><col style="width: 23.59%" /><col style="width: 76.41%" /></colgroup><thead><tr><th>名称</th><th>描述</th></tr></thead><tbody><tr><td><code>locale</code></td><td>要获取的翻译资源目标语言的 locale code，默认为当前 PingCode 用户的多语言设置，应保持不指定或设置为空。</td></tr></tbody></table>

### 返回值

返回值类型为 `GetTranslationsResult` ，表示获取翻译资源文件的内容：

<table style="width: 100%; table-layout: fixed"><colgroup><col style="width: 23.59%" /><col style="width: 76.41%" /></colgroup><thead><tr><th>名称</th><th>描述</th></tr></thead><tbody><tr><td><code>locale</code></td><td>指定翻译资源目标语言的 locale code</td></tr><tr><td><code>translations</code></td><td>针对指定 locale 的翻译文件解析后的内容。如果找不到该 locale 的翻译文件，函数返回空数组</td></tr></tbody></table>

### 示例

```typescript
import { i18n } from "@pc-nexus/bridge";

const { translations, locale } = await i18n.getTranslations();

console.log(JSON.stringify(translations, nulll, 2));
```

## createTranslator

通过 `createTranslator` 方法创建一个 Translator 对象，Translator 对象提供了 translate 函数可以根据 key 获取翻译内容，并提供参数替换的功能。

### 函数签名

```typescript
function createTranslator(locale?: SupportedLocaleCode): Promise<Translator>;

export interface Translator {
    translate: (key: string, params?: Record<string, any>) => TranslationsResourceContent | string;
}
```

### 参数

<table style="width: 100%; table-layout: fixed"><colgroup><col style="width: 23.59%" /><col style="width: 76.41%" /></colgroup><thead><tr><th>名称</th><th>描述</th></tr></thead><tbody><tr><td><code>locale</code></td><td>要获取的翻译资源目标语言的 locale code，默认为当前 PingCode 用户的多语言设置，应保持不指定或设置为空</td></tr></tbody></table>

### 返回值

返回值类型为 `Translator` ，表示指定语言资源内容的 Translator：

<table style="width: 100%; table-layout: fixed"><colgroup><col style="width: 23.59%" /><col style="width: 76.41%" /></colgroup><thead><tr><th>名称</th><th>描述</th></tr></thead><tbody><tr><td><code>translate</code></td><td>根据 Key 获取翻译的内容的函数</td></tr></tbody></table>

`translate` 函数参数如下：

<table style="width: 100%; table-layout: fixed"><colgroup><col style="width: 23.59%" /><col style="width: 76.41%" /></colgroup><thead><tr><th>名称</th><th>描述</th></tr></thead><tbody><tr><td><code>key</code></td><td>多语言定义的 key，例如 <code>title</code> 或者 <code>page.title</code></td></tr><tr><td><code>params</code></td><td>如果 key 对应的值有动态参数，那么通过 params 设置，比如 content 的值为 <code>你好，{{name}}</code> ，那么 params 设置为 <code>{ name: "Nexus" }</code></td></tr></tbody></table>

### 示例

```typescript
import { i18n } from "@pc-nexus/bridge";

const translator = await i18n.createTranslator();

// JSON: { page: { title: "标题", content: "你好，{{name}}" } }

const title = translator.translate("page.title");
const content = translator.translate("page.content", { name: "Nexus" });
```
