# Realtime

本文档介绍如何在 Nexus 应用中实现实时消息推送。实时消息推送是指 Nexus 应用通过实时消息频道，将实时更新消息发送到当前页面之外或多个用户的场景。

## 安装

```powershell
npm install @pc-nexus/realtime
```

导入：

```javascript
import { realtime } from "@pc-nexus/realtime";
```
