# i18n

`i18n` 模块可以读取你在 translation 中配置的翻译资源，为你提供国际化的能力。

导入：

```typescript
import { i18n } from "@pc-nexus/core";
```

内置方法：

<table style="width: 100%; table-layout: fixed"><colgroup><col style="width: 24.01%" /><col style="width: 75.99%" /></colgroup><thead><tr><th>API</th><th>描述</th></tr></thead><tbody><tr><td><code>getTranslations</code></td><td>获取指定语言的翻译资源</td></tr><tr><td><code>createTranslator</code></td><td>内置了一个 Translator 提供基础的翻译功能</td></tr></tbody></table>

## getTranslations

`getTranslations` 根据指定的语言获取翻译资源文件的内容。

### 函数签名

```javascript
function getTranslations(locale?: SupportedLocaleCode): Promise<GetTranslationsResult>

export interface TranslationsResourceContent {
    [key: string]: string | TranslationsResourceContent;
}

export interface GetTranslationsResult {
    locale: SupportedLocaleCode;
    translations: TranslationsResourceContent | null;
}
```

### 参数

<table style="width: 100%; table-layout: fixed"><colgroup><col style="width: 23.59%" /><col style="width: 76.41%" /></colgroup><thead><tr><th>名称</th><th>描述</th></tr></thead><tbody><tr><td><code>locale</code></td><td>要获取的翻译资源目标语言的 locale code，默认使用 translation 中配置的默认语言； <a href="https://at.pingcode.com/wiki/spaces/NEXUSHB/pages/Nh_LQAEG#JFnaT">支持的语言类型</a></td></tr></tbody></table>

### 返回值

通过 Promise 返回 `GetTranslationsResult` ，表示获取翻译资源文件的内容：

<table style="width: 100%; table-layout: fixed"><colgroup><col style="width: 23.16%" /><col style="width: 76.84%" /></colgroup><thead><tr><th>名称</th><th>描述</th></tr></thead><tbody><tr><td><code>locale</code></td><td>指定翻译资源目标语言的 locale code</td></tr><tr><td><code>translations</code></td><td>针对指定 locale 的翻译文件解析后的内容。如果找不到该 locale 的翻译文件，函数返回空数组</td></tr></tbody></table>

### 示例

```javascript
import { i18n } from "@pc-nexus/core";

/*
* "en-US": {
*     app: { version: "version: {{v}}" }
* }
*/

const { translations, locale } = await i18n.getTranslations("en-US");
console.log(translations); // { app: { version: "version: {{v}}" } }
```

## createTranslator

通过 `createTranslator` 方法创建一个 Translator 对象，Translator 对象提供了 translate 函数可以根据 key 获取翻译内容，并提供参数替换的功能。

### 函数签名

```javascript
function createTranslator(locale?: SupportedLocaleCode): Promise<Translator>;

export interface Translator {
    translate: (key: string, params?: Record<string, any>) => TranslationsResourceContent | string;
}
```

### 参数

<table style="width: 100%; table-layout: fixed"><colgroup><col style="width: 30.93%" /><col style="width: 69.07%" /></colgroup><thead><tr><th>名称</th><th>描述</th></tr></thead><tbody><tr><td><code>locale</code></td><td>要获取的翻译资源目标语言的 locale code，默认使用你在 <code>manifest.yaml</code> 中配置的默认语言； <a href="https://at.pingcode.com/wiki/spaces/NEXUSHB/pages/Nh_LQAEG#JFnaT">支持的语言类型</a></td></tr></tbody></table>

### 返回值

返回值类型为 `Translator` ，表示指定语言资源内容的 Translator：

<table style="width: 100%; table-layout: fixed"><colgroup><col style="width: 23.59%" /><col style="width: 76.41%" /></colgroup><thead><tr><th>名称</th><th>描述</th></tr></thead><tbody><tr><td><code>translate</code></td><td>根据 Key 获取翻译的内容的函数</td></tr></tbody></table>

`translate` 函数参数如下：

<table style="width: 100%; table-layout: fixed"><colgroup><col style="width: 23.59%" /><col style="width: 76.41%" /></colgroup><thead><tr><th>名称</th><th>描述</th></tr></thead><tbody><tr><td><code>key</code></td><td>多语言定义的 key，例如 <code>app.version</code></td></tr><tr><td><code>params</code></td><td>如果 key 对应的值有动态参数，那么通过 params 设置，比如 version 的值为 <code>version: {{v}}</code> ，那么 params 设置为 <code>{ v: "v1.0.0" }</code> ，最终得到文本 <code>version: 1.0.0</code> ；</td></tr></tbody></table>

### 示例

```javascript
import { i18n } from "@pc-nexus/core";

/*
* "en-US": {
*     app: { version: "version: {{v}}" }
* }
*/

const translator = await i18n.createTranslator( "en-US");
const version = await translator.translate("app.version", { v: "v1.0.0" });
console.log(version); // version: v1.0.0

const app = await translator.translate("app.version", {});
console.log(app); // { version: "version: {{v}}" }
```
