# Custom UI 构建前端界面

本指南详细阐述如何使用 Custom UI 构建应用前端界面。Custom UI 赋予开发者完全控制权来构建应用的用户界面。Custom UI 在 iframe 内运行，为应用的界面显示提供了一个隔离环境。

## 开发指南

Custom UI 支持使用不同的前端框架构建 UI，更多详情请参考：

- [使用 Angular 构建界面](/guide/development/custom-ui-with-angular)
- [使用 React 构建界面](/guide/development/custom-ui-with-react)
- [使用 Vue 构建界面](/guide/development/custom-ui-with-vue)
- [使用 JavaScript 构建界面](/guide/development/custom-ui-with-javascript)
- [Custom UI iframe 权限](/guide/development/custom-ui-iframe-permission)
